# Justine Basibas

I maintain [docx-repro](https://github.com/capt1nedev/docx-repro), an MIT-licensed developer tool for shrinking DOCX parser bug reports while preserving a specific symptom.

- [Try the installed demo](https://github.com/capt1nedev/docx-repro#runnable-example-missing-text-in-mammoth): 201 synthetic body blocks reduced to one.
- [Read a real bug investigation](https://github.com/capt1nedev/docx-repro/blob/v0.1.1/docs/case-study-2323.md): eight paragraphs reduced to two for a MarkItDown list report.
- [Release and downloads](https://github.com/capt1nedev/docx-repro/releases/tag/v0.1.1).
- [Install from PyPI](https://pypi.org/project/docx-repro/).
- [Runnable walkthrough](https://gist.github.com/capt1nedev/6946abc2bbd08ead1f8f26c68e16d1c7).
- [Report a case or contribute](https://github.com/capt1nedev/docx-repro/issues).

The project is an early alpha. Initial implementation was developed with Codex assistance and validated using tests and parser reproductions.
